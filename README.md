# Personal Portfolio Website

This project is a personal portfolio website created using HTML and inline CSS.

## Features

- Personal introduction
- About Me section
- Skills section
- Projects section
- Contact section
- Navigation links
- Inline CSS styling

## Technologies Used

- HTML5
- Inline CSS

## Purpose

The purpose of this project is to understand how inline CSS can be applied directly to HTML elements to change:

- Font color
- Font size
- Background color
- Spacing
- Borders
- Buttons
- Overall webpage appearance
